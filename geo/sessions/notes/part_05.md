## Traps and gotchas
- **Paste channel strips mid-line `#` and backslashes.** This was the single biggest time sink. `while [ $# -gt 0 ]; do` arrived as `while [ $` (the `; do` eaten as a comment); `sed -E 's/^# ?//'` and `$'...'` quoting also broke. Diagnosis: perfect correlation between count of mid-line `#` per file and Boris's reported failure location (daily "fails on first while loop" = line 36; probe "fails on first case" = line 44). Fix: rewrite to eliminate mid-line `#` and backslashes, verify with `grep -nE` for mid-line hash and `grep -c '\\'` = 0, and ultimately deliver via git pull instead of paste.
- **The blank-line red herring.** Instance first explained hash mismatches as dropped blank lines (cosmetic). Boris's non-blank counts disproved it: 13/9/11 real code lines were missing, not whitespace. Instance explicitly retracted. Lesson recorded: non-blank-line hash is the real test.
- **`classify_ranges -dry-run` skipped creating `range_classification`** but the query referenced it → crash. Fix: create the table first (`CREATE TABLE IF NOT EXISTS`).
- **`-preserve-routeviews` default (`conditional`) silently discards all 489,348 /24 rows** because apply_splits already DELETEd the wider db-ip parents the test looks for. Must use `all`. The importer now warns if every routeviews row is dropped, but the flag prevents it.
- **`:'DMA'` psql variable fails as plain `psql -f`** → `syntax error at or near ":"`. Worked only with `-v DMA=`. Not a logic bug but a fragile design. Fixed by switching to `SET geo.dma` GUC (also backslash-free, paste-safe).
- **`CREATE TEMP TABLE ... AS SELECT` emits a `SELECT N` command tag** that corrupted the piped CIDR list and made `expand_cidrs` fail on line 1. Fix: inline the literal in the two piped queries.
- **Measured-city variant can silently drop ranges from a DMA.** A range db-ip labels "Indianapolis" may measure as "Greenwood"/"Fishers"; if `dma2city_tbl` lacks that city it falls out. This is a real false-negative hazard, not a bug. (Boris's real table has 263 cities so coverage is good; DMAs are county-defined — Greenwood→Johnson, Fishers→Hamilton — so a zip→county→dma join would be more robust than city-name matching.)
- **Instance fabricated a test fixture and reported its artifact as if it were Boris's data** (the Greenwood exclusion). Instance had never queried the real `dma2city_tbl`. It retracted and admitted it should have been explicit that it had no DB visibility.
- **Merge add/add conflicts** because `main` was built from GitHub web-UI "Add files via upload" of the same paths. For `bgp_route_views` main was newer (doc comments only; code byte-identical by comment-stripped hash). A nested `check_geo_ip-api/cmd/go.mod` from main broke `go build ./cmd` from the parent module — dropped it.
- **`/home/boris` is 0700**, so `cronuser` cannot traverse it regardless of script modes (`namei -l` named it precisely); `cronuser` is in no shared group. Chosen fix: relocate the tree to `/var/trugeo` (root-owned, world-readable) rather than weaken the home dir.
- **`dbip-mmdb-import` DROP TABLE + RENAME needs table ownership, not just GRANT ALL.** Fix: `GRANT boris TO cronuser` so the service account inherits ownership rights while boris stays owner.
- **`flock -w N` gave up and killed the job** — wrong for long worldwide ingests. Replaced with indefinite wait + alert thresholds; a lock is held for the whole job (fd closes on any exit), never a lease.
- **cron.d files are silently disabled** if not root-owned / not mode 0644 / executable / filename has a dot / missing trailing newline.
- **`/home/cronuser/geo-logs` existed but was not writable by cronuser; scripts carried on with every log line discarded** (`tee: Permission denied` but exit continued). Fix: make the unwritable LOG_DIR fatal, and move logs to `/var/log/trugeo` (chown cronuser). Also note: root bypasses directory permissions, so testing the guard as root is invalid — must test as an unprivileged user.
- **`PGOPTIONS` breaks on spaces** — unusable for passing the DMA name; a GUC via `-c SET` works because `-c` and `-f` share one session.
- **Start-email fires after locks acquired**, so a run that exits because another holds the lock sends no mail at all (no "starting" and no "finished").
- **traceroute-sample lives at a different path locally (`~/geo/traceroute-sample/cmd/main.go`) than in the repo (`geo/main.go`)** — the patch list (derived from the repo) missed it; it also has no `go.mod` anywhere so cannot currently be rebuilt. `~/geo` and the git checkout are separate trees (caused earlier path divergence).
- **GeoNames IDs are uint32** in DB-IP, so the importer uses `bigint` to avoid overflow; `char(2)` avoided in favour of `text`.
