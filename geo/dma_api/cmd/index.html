TruGeo DMA address lookup

Select a DMA to see how much address space it covers, then download the ranges or the full address list.

Codes are used rather than names because DMA names vary in punctuation and suffix between sources, and a mismatched name returns nothing at all.

Network and broadcast addresses are included. In a range wider than /24 they are ordinary usable addresses.

Add gzip=1 to compress, or max=N to refuse a result larger than N addresses.
